# Customer Behavior Dashboard

## Project Overview
This project analyses customer shopping behaviour using SQL, Python, PostgreSQL, and Power BI. It explores customer spending patterns, product categories, reviews, discounts, subscriptions, and repeat purchases.

## Tools & Technologies
- **SQL & PostgreSQL:** Business queries and customer data analysis
- **Python & Pandas:** Data cleaning and feature engineering
- **Power BI:** Interactive dashboard and data visualization

## Project Workflow
1. Explored and cleaned the customer shopping dataset using Python and Pandas.
2. Handled missing review ratings and created age-group and purchase-frequency features.
3. Loaded the prepared data into PostgreSQL for SQL-based analysis.
4. Analysed customer spending, product ratings, discounts, subscription status, and repeat purchases.
5. Built an interactive Power BI dashboard with KPI cards, charts, and slicers.

## Key Insights
- Clothing generated the highest revenue among product categories.
- Young Adult customers generated the highest revenue among age groups.
- Non-subscribed customers contributed more revenue than subscribed customers.
- Subscription patterns can be explored further to understand customer engagement.

- SQL file: Business analysis queries
